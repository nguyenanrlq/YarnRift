# YarnRift

YarnRift enables intelligent, distributed workflows via adaptive, auto-scalable clusters with dynamic resource allocation and advanced manager engine capabilities.

YarnRift is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/YarnRift.git`
2. `cd YarnRift`
3. Install in editable mode: `pip install -e .`

## Configuration

YarnRift is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
